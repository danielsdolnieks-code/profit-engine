# Profit Engine

A static, accessible finance simulator for Managerial Finance Day 2. Compare current and proposed prices, sales volumes, variable costs and fixed costs. Includes two products, avoidable fixed costs, shared overhead allocation, break-even, margin of safety, contribution targets and machine capacity.

Deploy to Vercel using the Other framework preset, no build command, and the repository root as the output directory. No dependencies, accounts or server are needed. Scenarios save locally in the current browser; they do not sync across devices. The main screen starts with one product and four inputs. Explore more reveals the second product, capacity, cost allocation and detailed comparisons. Reset example replaces the saved scenario.

Open `index.html` in a browser for local use. Run `node test.cjs` to check the finance rules.
